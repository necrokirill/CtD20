# Changeling: The Dreaming (C20) — Полное руководство игрока

Иллюстрированный русскоязычный справочник игрока по **Changeling: The Dreaming 20th Anniversary Edition** в оформлении **«Ар-Нуво и Золото»**, подготовленный для публикации на **GitHub Pages**.

## Возможности сайта

- **Стиль «Ар-Нуво и Золото»:** обсидианово-изумрудный бархат, двойные золотые рамки без искажений углов, буквицы и динамическая аура каждого тома и Кита.
- **Структура из 10 томов:** оглавление всего руководства (Тома `01`–`09`, включая двухтомный Гримуар Искусств `08А` и `08Б`) с индикацией прогресса перевода.
- **Витражные Арканы 13 Китов (Часть 2):** полный перевод всех 13 базовых Китов Конкордии с фильтрацией по Сродству, сменой ауры страницы, вкладками *История и Облик / Права и Слабость / Стадии души / Стереотипы*, режимом сплошного чтения, конструктором собственного Кита и сводной шпаргалкой.
- **Единый Лексикон игрока (55+ понятий):** автоматическое подчёркивание терминов золотым пунктиром во всех главах, всплывающие карточки с **цепочками переходов (в стиле BG3)** на ПК и выдвижной шторкой на смартфонах.
- **Интерактивные виджеты правил:** тренажёр Темпераментов (*Младенец / Дикарь / Ворчун + Дом Лиам*) и витражное уравнение Кантрипа.
- **Режим стола и Печать в PDF:** мгновенное скрытие художественного лора для игры за столом, глобальный поиск (`Ctrl+K`) и чистая книжная вёрстка `@media print` на белом листе А4.

## Быстрый запуск Веб-Админки и предпросмотра

Требуется только **Python 3.10+** (внешние `pip`-пакеты не нужны):

1. Запустите файл **`Start-Admin.bat`** двойным кликом *(или выполните в терминале `python tools/admin.py`)*.
2. В браузере откроются:
   - **Студия Издателя (Админка):** `http://127.0.0.1:8080/admin`
   - **Живой сайт книги:** `http://127.0.0.1:8080/`

### Что умеет Веб-Админка
- **Тома и Обзор:** переключение статусов глав (`Готово` / `В переводе` / `В планах`), настройка цветов ауры и титульного листа.
- **Редактор Глав:** редактирование Markdown с живым предпросмотром «Ар-Нуво», панель вставки блоков (`:::lore`, `:::mechanics`, `:::sidebar Заголовок`), загрузка обложек и вставка картинок прямо из буфера обмена по **`Ctrl+V`**.
- **Форматы рамок для иллюстраций в тексте:**
  - `![Подпись](assets/images/chapters/pic.webp)` — двойная золотая рамка по центру
  - `![arch:Подпись](assets/images/chapters/pic.webp)` — витражная арка Ар-Нуво
  - `![right:Подпись](assets/images/chapters/pic.webp)` — обтекание справа в тексте
  - `![left:Подпись](assets/images/chapters/pic.webp)` — обтекание слева в тексте
  - `![wide:Подпись](assets/images/chapters/pic.webp)` — широкая панорама
- **Арканы Китов:** редактирование всех 13 Китов и загрузка индивидуальных портретов в карточки Арканов.
- **Лексикон:** добавление и правка терминов с кнопкой **«✦ Сгенерировать падежи»** для авто-ссылок.

## Публикация на GitHub Pages

Поддерживаются оба стандартных способа на выбор:
1. **Через GitHub Actions (рекомендуется):** в настройках репозитория откройте **Settings → Pages → Source** и выберите **GitHub Actions**. При каждом `git push` скрипт `.github/workflows/deploy-pages.yml` сам запустит `python tools/build.py` и опубликует сайт.
2. **Напрямую из папки `/docs`:** поскольку Веб-Админка и `python tools/build.py` сразу обновляют папку `docs/`, можно выбрать **Deploy from a branch → `main` → `/docs`**.
